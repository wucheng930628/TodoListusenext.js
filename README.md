# Slowly — 我的任務看板

使用 Next.js 與 React 製作的 Kanban 風格 Todo List。支援多看板、任務詳情側邊面板、週曆與月曆，並可透過自訂小組件整理任務進度、專注計時與筆記。

首頁預設使用瀏覽器的 `localStorage`，可直接使用看板、任務與小組件。專案也提供以 DynamoDB Local 為後端的本機 API。API 模式須明確啟用，正式 API 寫入目前關閉。

## 功能

### 多看板與任務管理

- **獨立看板** — 新增、切換看板，各自保存任務、名稱、描述、WIP 上限與小組件配置。新看板從空白任務清單開始。
- **看板設定** — 點擊標題旁的齒輪調整設定，進行中上限預設為 4 件，可設定為 1–100 件，包含優先處理泳道的任務。
- **三欄看板** — 待處理、進行中、已完成，可拖曳卡片或使用狀態選單移動任務。
- **任務詳情側邊面板** — 點擊卡片即可編輯任務名稱、描述、狀態、分類、優先級、截止日期與時間，以及備註。
- **子任務** — 支援新增、修改、勾選與刪除，卡片顯示子任務完成數，面板顯示完成進度。
- **分類與優先級** — 分類包含個人、工作、設計、開發、生活，優先級包含低、一般、高。
- **優先處理泳道** — 將重要任務放入看板下方的優先處理區域，可透過拖曳或任務面板切換。
- **搜尋與篩選** — 依任務名稱、描述與分類搜尋，並切換全部任務、未完成或高優先，適用於清單及行事曆。
- **截止與逾期標示** — 時間可選填，未完成且逾期的任務會以紅色顯示「已逾期」。只填日期時，以當天結束為截止點。
- **即時時間與通知** — 頁面右上角顯示日期與時分秒，每秒更新，操作通知在 3 秒後自動關閉。

### 行事曆

- **清單、週曆與月曆切換** — 顯示目前看板的任務。
- **時間格線週曆** — 以週一為起點，顯示 00:00–23:00 時段，依截止時間定位任務，重疊的卡片會並排，今天顯示現在時間指示線。
- **月曆** — 以七欄日期格查看任務，同一天的任務依截止時間排序。
- **日期導航** — 支援上一週／月、下一週／月、回到今天及指定日期跳轉。
- **快速新增與編輯** — 點選週曆時段或月曆日期新增任務，點選任務開啟側邊面板。
- **未排程任務** — 缺少截止日期的任務列在行事曆下方，只填日期的任務列在週曆上方「未設時間」區域。

### 自訂小組件

點擊「新增小組件」，可從選單拖入或點擊「加入」。每個小組件為獨立 React component。

| 小組件 | 功能 |
| --- | --- |
| 任務完成統計 | 近 7 天完成數長條圖、整體與本週完成率圓環、今天完成數、逾期數量、連續完成天數 |
| 今日待辦 | 查看今天到期的任務，可設定是否包含已完成任務 |
| 即將到期 | 查看今天起共 7 個日曆日內到期的任務，可設定是否包含已完成任務 |
| 番茄鐘 | 選擇專注任務，支援開始、暫停、重設，可設定為 15、25、45 或 60 分鐘 |
| 快速筆記 | 輸入看板備忘，內容自動保存在瀏覽器 |

- **排序** — 拖曳標題列的握把，或使用前後移動按鈕。
- **尺寸調整** — 拖曳右下角，或聚焦調整按鈕後使用方向鍵。內容會隨大小縮放或重排，手動設定的尺寸會保存。
- **自動排版** — 自動尺寸的組件分配每排剩餘寬度，同排自動組件會對齊高度。手動尺寸的組件依照儲存的寬高顯示。
- **個別移除** — 點擊組件右上角的「×」。移除有內容的快速筆記前會顯示確認訊息。
- **全部清空** — 點擊「新增小組件」旁的重設圖示，確認後刪除目前看板全部小組件，包含筆記內容與組件設定。
- **獨立保存** — 各看板保存自己的組件種類、順序、尺寸、筆記與番茄鐘狀態。

### 響應式與本機儲存

窄螢幕提供看板切換選單，小組件改為單欄，看板與行事曆可橫向捲動。重新整理後會讀回目前瀏覽器保存的看板、任務與小組件資料。

## 安裝與啟動現有專案

在包含 `mytodolist` 的目錄開啟終端機，執行下列指令。若已經位於專案目錄，可略過第一行。

```bash
cd mytodolist
npm ci
npm run dev
```

啟動後，在瀏覽器開啟 `http://localhost:3000`。若 3000 埠已被占用，請使用終端機實際顯示的網址。

`npm ci` 會依照 `package-lock.json` 安裝相同版本的依賴。修改程式後，開發伺服器會自動更新頁面。

### Windows PowerShell

若執行 npm 時出現「已停用指令碼執行」錯誤，可使用 `.cmd` 指令。

```powershell
cd mytodolist
npm.cmd ci
npm.cmd run dev
```

以下的 npm、npx 指令也可分別改成 `npm.cmd`、`npx.cmd`。

### 選用 DynamoDB Local

預設看板可直接用 `npm run dev` 啟動。開發或驗證本機 API 時，請先啟動 Docker，再於 `mytodolist` 目錄執行：

```powershell
docker compose up -d dynamodb-local
docker compose ps dynamodb-local
```

Compose 將 DynamoDB Local 繫結在 `http://127.0.0.1:9000`，資料保存在專案的 `./data/`。如果埠 9000 已有 DynamoDB Local 運作，請先確認要使用哪個執行個體，避免同時啟動兩個。

若要啟動本機 API 開發伺服器，請確認埠 3000 可用，再執行 `npm run dev:api`。API 與工作區的使用範圍請參考 [本機 API 文件](docs/phase3-api.md) 和 [Phase 5-E 交付手冊](docs/phase5e-delivery.md)。使用 `docker compose stop dynamodb-local` 可停止服務並保留 `./data/`。

## 從零建立 Next.js 專案

這段流程用於建立新的專案骨架。請在尚未存在 `mytodolist` 資料夾的位置執行。

```bash
npx create-next-app@16.4.6 mytodolist --js --eslint --tailwind --app --src-dir --import-alias "@/*" --use-npm
cd mytodolist
npm run dev
```

若出現額外設定提問，可依開發需求選擇。建立後，將本專案完整的 `src/app/` 目錄加入新專案，包含頁面、各功能 component 與對應 CSS，即可套用看板介面與功能。

要重現本專案的完整依賴與 Turbopack 樣式設定，請使用現有專案中的 `package.json`、`package-lock.json` 與 `next.config.mjs`，再執行 `npm ci`。初始化工具建立的骨架與設定可能有所差異。

## 使用方式

1. 首次開啟時會顯示範例任務，可直接編輯或刪除。
2. 點擊右上角「新增任務」，或各欄底部的「新增任務」。
3. 在右側面板填寫任務名稱，視需要補上描述、分類、優先級、截止日期與時間、子任務及備註。
4. 勾選「優先處理」，即可將任務放到下方泳道。
5. 點擊「儲存任務」完成新增。之後可點擊卡片或「•••」再次編輯。面板中的修改需按下儲存才會套用，取消、關閉或按 Esc 會放棄本次修改。
6. 拖曳卡片或使用狀態選單調整進度。進行中達上限時，先移出或完成任務，才能加入下一件。可透過標題旁齒輪修改上限。
7. 切換「週曆」或「月曆」查看截止安排，點選時段或日期可直接帶入日期與時間新增任務。
8. 點擊「新增小組件」加入工具，再拖曳排序或調整大小。任務統計會顯示目前看板全部任務的進度。
9. 點擊側欄「新增看板」建立其他工作空間，再從側欄或手機版選單切換。

## 注意事項

### 資料保存

- 看板、任務與小組件儲存在目前瀏覽器、目前網站來源的 `localStorage`，使用的 key 為 `slowly-workspace-v2`。
- 如果只找到舊版 `slowly-board-v1`，系統會保留原始資料並提示使用備份檢查流程。
- 清除網站資料、更換瀏覽器或使用其他裝置，會影響能讀取的任務紀錄。不同網域或連接埠也會使用各自的儲存空間。
- 無痕模式中的紀錄可能在關閉視窗後移除。
- 目前以單一分頁操作為主，多個分頁同時編輯時，後寫入的內容可能覆蓋先前紀錄。
- 開發模式可從「資料來源」匯出完整本機備份。Git 保存程式碼，瀏覽器資料與 DynamoDB Local 的 `./data/` 需另外保存。
- 若瀏覽器阻擋儲存或空間不足，畫面會顯示通知。此時的變更僅保留在目前開啟的頁面。

### 任務操作

- 任務名稱必填，最多 100 字元，描述最多 1,000 字元，備註最多 5,000 字元，子任務名稱最多 150 字元。
- 子任務可透過「加入」或 Enter 新增。完成全部子任務後，主任務狀態仍由使用者調整。
- 日期、時間、逾期與每日統計使用瀏覽器所在時區。右上角時間與逾期標示會隨時間更新。
- 行事曆依截止時間定位任務，每張卡片表示一個截止點。任務目前可記錄截止日期與時間，到期時會顯示逾期狀態。
- 卡片移動會更新狀態與泳道。受授權的隔離 API 寫入模式支援同欄卡片排序。
- 觸控裝置上的拖曳支援依瀏覽器而異，可使用狀態選單移動任務，並透過編輯視窗切換泳道。

### 統計計算

- 整體完成率以目前看板已完成任務數除以全部任務數，包含優先處理泳道中的任務。
- 本週從週一開始。本週完成率以本週到期或本週完成的任務為範圍，計算其中已完成的比例。
- 近 7 天長條圖與今天完成數依任務的 `completedAt` 完成時間計算。
- 任務移入已完成時會記錄完成時間，編輯已完成任務會保留該時間。重新開啟任務會清除完成時間，再次完成則記錄新的時間。
- 連續完成天數由今天往前計算。今天尚未完成任務時，會從昨天起算，直到遇到沒有完成紀錄的一天。
- 既有完成任務若缺少完成日期，會計入整體完成率，每日完成數則使用有完成日期的紀錄。
- 統計依目前仍保存的任務計算，刪除任務後會同步更新統計。

### 小組件使用

- 快速筆記最多 10,000 字元，輸入時會自動保存。
- 清空全部小組件會刪除目前看板的小組件內容與設定，確認前請留意筆記內容。
- 手動調整的小組件寬度以 12 欄網格為基礎，支援 4–12 欄，高度可調整為 170–600px。窄螢幕會以單欄顯示。
- 番茄鐘使用儲存的結束時間計算剩餘秒數。重新整理或切換看板後會繼續計算，暫停則保留剩餘時間。
- 番茄鐘完成後會在組件中顯示「專注完成」，目前以頁面內狀態提示為主。

### 安裝與建置

- 安裝依賴需要網路連線。`layout.js` 使用 `next/font/google` 載入 Geist 字型，首次開發或建置也可能需要連線至 Google Fonts。
- 若出現 `Failed to fetch Geist from Google Fonts`，請檢查網路連線與代理設定，再重新執行建置。
- 請保留 `package-lock.json`，讓其他開發者能透過 `npm ci` 安裝一致的依賴。
- `node_modules` 與 `.next` 已列入 `.gitignore`，由安裝與建置指令產生。
- 專案檔案使用 UTF-8 編碼，編輯中文內容時請維持相同編碼。
